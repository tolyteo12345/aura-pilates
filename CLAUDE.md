# Claude project instructions

Read and follow [AGENTS.md](AGENTS.md) in full before planning, editing or reviewing code in this repository. `AGENTS.md` is the single authoritative source of project rules for both Claude and Codex, including the required workflow for new features and the mandatory frontend rules in [docs/design-system.md](docs/design-system.md).

For every new feature, inspect the relevant existing source code and identify the closest implementation pattern before planning or editing. For every frontend change, read [docs/design-system.md](docs/design-system.md) in full before planning or editing. Stop and report a blocker if the relevant source or required documentation cannot be read.

Also follow every more-specific `AGENTS.md` or `CLAUDE.md` on the path to a file being changed. Those files may add constraints but cannot weaken the two requirements above unless the user explicitly directs otherwise.
